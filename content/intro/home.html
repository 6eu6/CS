Your companion for CS50's Introduction to Programming with Python

CS50P teaches you Python in ten weeks of lectures and problem sets. This companion sits next to it: every idea from each week explained down to the last symbol, decision guides for "when do I use this vs that", realistic scenarios, and hundreds of practice runs that check themselves.

How this fits with CS50P

This site does not replace the lectures or solve the problem sets. The lectures teach; this companion makes sure you understand every detail; the problem sets are where you prove it, on your own. The practice here is all original and deliberately different from CS50's problem sets, so you build the skill without seeing their answers.

The roadmap

What "mastery" means here

By the end of each week you should be able to do four things without help:

  1. Explain every line of the week's code out loud, including the symbols.
  2. Choose the right tool for a situation (e.g. / or //, print or return) and say why.
  3. Write a small program from a blank file using that week's ideas.
  4. Debug it: read the error message and fix the cause.

Each week ends with a checklist of exactly these skills. Tick them off honestly; it's the best signal of whether you're ready for the next week.
