Pocket Ledger · Week 3

Part D: resilient transaction parsing

A real bank export contains malformed rows. Your parser must reject invalid records clearly without crashing the whole import.

Acceptance criteria

  • Parse date, description and amount into the correct types.
  • Reject missing fields and non-numeric amounts with ValueError.
  • Keep valid records when one row is bad; report rejected rows separately.
  • Never silently turn an invalid amount into zero.
