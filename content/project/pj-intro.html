Main project

Pocket Ledger: one app that grows with you

One part per weekYour code carries over

Pocket Ledger is a personal finance tool: it reads your transactions, sorts them into categories, totals your spending, warns you about budgets and produces reports. Each week of the course adds one part using that week's tools. By the end it's a real program you could put on GitHub and use yourself.

How parts connect

When you open a new part, its editor starts with your own final code from the previous part (or the reference version if you haven't finished it). You extend your program, just like real software. Parts D–J are built as you reach each week.
