Pocket Ledger · Week 9

Part J: ship the command-line app

Turn the project into a maintainable command-line application with documented commands and predictable exit behaviour.

Acceptance criteria

  • Provide summary and categories commands with argparse.
  • Add type hints and docstrings to public functions.
  • Separate parsing, domain logic, persistence and presentation.
  • Document installation, sample data, tests and limitations.
  • Run the test suite from a clean environment before release.
