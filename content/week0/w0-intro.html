Week 0 · Functions, Variables

Week 0: the building blocks

6 lessonsPractice labWeek test

Everything in Python is built from a few pieces you meet this week: functions you call, values you store in variables, text you shape, numbers you calculate with, and functions you write yourself.

What you'll be able to do

  • Make print output exactly what you want, including on one line, with custom separators and special characters.
  • Get input from a user and clean it up: remove spaces, fix capitals, replace text.
  • Convert text to numbers safely, and know which kind of number and which operator to use.
  • Format results: decimal places, thousands separators, money.
  • Write your own functions with parameters, default values and return values, and know where each variable "lives".
