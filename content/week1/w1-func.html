Modulo for parity

if n % 2 == 0:       # remainder 0 when divided by 2 → even
    print("Even")

Boolean functions

def is_even(n):
    return n % 2 == 0        # the comparison IS the answer

# not this:
def is_even(n):
    if n % 2 == 0:
        return True
    else:
        return False

Name them as yes/no questions: is_valid, has_ticket, can_vote. Then if is_even(n): reads like English. Never write if is_even(n) == True:; the function already gives a bool.

Pythonic code

"Pythonic" means using the language the way experienced Python programmers do: short, clear, no unnecessary steps. Returning the comparison directly is Pythonic. So is the conditional expression:

label = "even" if n % 2 == 0 else "odd"
print(f"{n} item{'s' if n != 1 else ''}")     # "1 item", "2 items"

Guard clauses (early return)

def shipping(total, country):
    if country != "UK":
        return "International rates apply"
    if total >= 50:
        return "Free"
    return "£3.99"

Each return ends the function, so no else is needed. Handle the special cases first, then the normal case without extra indentation.

match (Python 3.10+)

match command:
    case "start" | "go":
        print("Starting")
    case "stop":
        print("Stopping")
    case _:
        print("Unknown command")

match compares one value against several patterns; | means "or"; case _ catches everything else. (The runners on this site run real Python 3.12, so match works right here.)
