Comparisons and if, elif, else

Every comparison produces True or False

age = 17
print(age >= 18)        # False
can_vote = age >= 18    # you can store the answer in a variable

True and False are values of type bool (named after George Boole, who invented the algebra of logic). A comparison is an expression whose value is a bool.

OperatorQuestionExample → result
==equal?3 == 3.0 → True (numbers compare by value)
!=not equal?"a" != "A" → True (case matters)
< >less / greater?"apple" < "banana" → True (alphabetical, character by character)
<= >=…or equal?50 >= 50 → True
Two classic traps

= stores a value; == compares. And "10" < "9" is True because strings compare character by character. input() gives strings, so convert with int() before comparing numbers.

Chained comparisons

print(0 <= score <= 100)     # Python reads this like maths: is score between 0 and 100?

Anatomy of if / elif / else

Exactly one branch runs

Python checks the conditions top to bottom and runs the first branch whose condition is true. Then it skips the rest, even if later conditions are also true. If none match, else runs (if there is one).

Order matters

# WRONG: 95 gets "C"
if score >= 50:
    grade = "C"
elif score >= 60:
    grade = "B"
elif score >= 70:
    grade = "A"
# RIGHT: most specific first
if score >= 70:
    grade = "A"
elif score >= 60:
    grade = "B"
elif score >= 50:
    grade = "C"

With thresholds, test from the highest down, so each branch only needs one boundary: the earlier branches have already ruled out everything above.

One chain or several ifs?

x = 15
if x > 10:
    print("big")         # separate ifs: EACH one is checked
if x > 5:
    print("medium")      # → prints big AND medium

if x > 10:
    print("big")         # one chain: only the first true branch
elif x > 5:
    print("medium")      # → prints big only

Use one chain when the cases are exclusive (one grade, one ticket price). Use separate ifs when several things can be true at once.
