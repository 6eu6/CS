Choosing the right decision tool

SituationUseBecause
Exclusive cases with ranges (grades, tax bands, prices by weight)if / elif / else, orderedRanges need comparisons; order removes repeated boundaries
Several independent checks (password rules)separate ifsMore than one can be true
Fixed commands with different actionsmatch (3.10+) or if/elifReads like a menu
Choosing between two valuesconditional expressionOne line, no repeated assignment
Special cases inside a functionguard clauses with early returnFlat code, normal case last
A yes/no question you'll ask in many placesa Boolean functionName it once, read it everywhere
A default when input is emptyvalue or "default"Short, idiomatic
