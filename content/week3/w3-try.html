Catching exceptions

An exception is a runtime signal that normal execution cannot continue at that point. Handle the specific failure you expect.

try and except

try:
    age = int(input("Age: "))
except ValueError:
    print("Please enter a whole number.")

The risky operation belongs inside try. If it raises ValueError, Python runs the matching handler. Other exceptions still surface, helping reveal bugs.

else and finally

try:
    number = int(input("Number: "))
except ValueError:
    print("Not a whole number")
else:
    print(number * 2)
finally:
    print("Attempt finished")
  • else runs only when try succeeds.
  • finally runs whether an exception happened or not; use it for cleanup.
