Choosing an error strategy

A robust program separates user mistakes, invalid domain values, and genuine programming defects.

while True:
    try:
        amount = float(input("Amount: "))
    except ValueError:
        print("Enter a number, such as 12.50.")
        continue
    if amount <= 0:
        print("Amount must be positive.")
        continue
    break

Conversion errors are handled narrowly. A valid number that violates the business rule is handled separately. The loop exits only after valid input.

  • Catch the narrowest useful exception.
  • Give actionable messages.
  • Never silently replace invalid data with a plausible default.
  • Keep unexpected exceptions visible while developing.
  • Test valid and invalid paths.
