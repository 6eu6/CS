Week 3 · Exceptions

Week 3: resilient programs

ExceptionsValidationDefensive programming

Real programs receive unexpected input and encounter failures. This week teaches you to handle expected errors deliberately, reject invalid data clearly, and leave unexpected bugs visible.

Outcomes

  • Distinguish syntax, runtime and logical errors.
  • Use try/except/else/finally precisely.
  • Raise exceptions when function contracts are broken.
  • Validate data at program boundaries.
  • Build retry loops without hiding unrelated bugs.

Route

  1. Catching exceptions
  2. Raising and validating
  3. Choosing a safe strategy
  4. Practice lab
  5. Mastery test
