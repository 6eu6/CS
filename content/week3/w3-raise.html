Raising and validating

A function should protect its own contract. If a caller supplies an impossible value, raise a clear exception instead of silently returning nonsense.

def withdraw(balance, amount):
    if amount <= 0:
        raise ValueError("amount must be positive")
    if amount > balance:
        raise ValueError("insufficient funds")
    return balance - amount

Use ValueError when the type is acceptable but the value is not. Use TypeError when the kind of object is inappropriate. Validate at boundaries, then keep internal code simple.

Do not use exceptions as ordinary branching: check normal conditions directly.
