split() and join(): text to pieces and back

35 min4 scenarios · 5 exercises
The question it answers

split: "How do I break this line of text into its parts?" join: "How do I glue a list of strings into one line?" They are exact opposites.

Anatomy of join (the one everyone finds odd)

Why is it ", ".join(list) and not list.join(", ")?

Because join belongs to strings, and it works on any iterable of strings: lists, tuples, generators, dict keys. Putting it on the separator means one method serves them all. Read it as: "use ", " to join these".

split in detail

"a  b\tc\n".split()        # ['a', 'b', 'c']        no argument: any whitespace, runs merged, ends ignored
"a,,b".split(",")           # ['a', '', 'b']         with a separator: every comma counts, empties kept
"k=v=w".split("=", 1)       # ['k', 'v=w']           maxsplit: only split once
"".split(",")               # ['']                   one empty piece, not an empty list!

join in detail

", ".join(["tea", "jam"])           # 'tea, jam'
"".join(["a", "b", "c"])            # 'abc'
"\n".join(["line 1", "line 2"])     # two lines in one string
", ".join([1, 2])                   # TypeError: expected str instance, int found
", ".join(str(n) for n in [1, 2])   # '1, 2'
Building strings: join beats +=

s += piece in a loop is fine for small jobs, but each += creates a whole new string. Collecting pieces in a list and joining once at the end is the professional habit, and it's much faster for large output.

Real-work scenarios

Scenario 1: Parsing a log line

line = "2026-11-02 14:03:55 ERROR Payment declined for order 1182"
date, time, level, message = line.split(" ", 3)
print(level, "|", message)    # ERROR | Payment declined for order 1182

maxsplit=3 splits only at the first three spaces, so the message stays in one piece however many words it has.

Scenario 2: Writing a CSV row

row = ["Sara", 42, "London"]
print(",".join(str(v) for v in row))     # Sara,42,London

Scenario 3: Cleaning every field

raw = " Sara , 42 ,  London "
fields = [f.strip() for f in raw.split(",")]
print(fields)            # ['Sara', '42', 'London']

Scenario 4: Human-friendly lists

items = ["tea", "milk", "bread"]
print(", ".join(items[:-1]) + " and " + items[-1])     # tea, milk and bread
