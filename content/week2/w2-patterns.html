The seven loop patterns

40 minPattern identification drill · 6 exercises

Experienced programmers don't invent loops from scratch. They recognise which pattern a problem needs and adapt it. Almost every loop you'll write in CS50P is one of these seven, or two of them combined.

1. Sum (accumulate)

total = 0                 # start at the "nothing" value for addition
for price in prices:
    total += price

Use for: totals, averages (sum ÷ count), running balances. The starting value is 0 for sums, 1 for products, "" for building text.

2. Count

count = 0
for t in temps:
    if t > 25:
        count += 1        # add 1, not t

Use for: "how many…" questions. The difference from sum: you add 1, not the value.

3. Maximum / minimum (best so far)

best = scores[0]          # start with a REAL item, not 0
for s in scores:
    if s > best:
        best = s

Use for: highest, lowest, longest, earliest. Start with the first item, because starting at 0 breaks when all values are negative. (max() exists, but you need this pattern when you also want e.g. who had the best score.)

4. Filter (keep some)

passed = []
for s in scores:
    if s >= 50:
        passed.append(s)

Use for: "all the ones that…". Builds a new list; the original is untouched.

5. Transform (change each)

clean = []
for name in names:
    clean.append(name.strip().title())

Use for: converting every item: tidying, converting units, adding VAT.

6. Search (find the first)

found = None
for email in emails:
    if email.endswith("@nhs.net"):
        found = email
        break             # stop at the first match
if found is None:
    print("Not found")

Use for: "is there one that…?" or "the first one that…". The break saves time; None means "nothing yet".

7. Tally (count each kind)

tally = {}
for vote in votes:
    tally[vote] = tally.get(vote, 0) + 1

Use for: "how many of each?" Uses a dictionary. The word counter is this pattern.

Combining patterns

"Average of the scores above 50" = filter + sum + count. "Name of the student with the best score" = max pattern, tracking the whole record instead of just the number. When you face a new problem, first ask "which patterns is this?"
