enumerate(): the item and its position, together

30 min4 scenarios · 6 predictions · 4 exercises
The question it answers

"While looping, I need each item and which number it is."

Anatomy

What it really produces

list(enumerate(["tea", "jam"]))      # [(0, 'tea'), (1, 'jam')]
list(enumerate(["tea", "jam"], 1))   # [(1, 'tea'), (2, 'jam')]

Each step gives a pair (a tuple). for i, item in … unpacks the pair into two variables. The optional second argument is where counting starts.

New: tuples

A tuple is like a list written with round brackets, ("Sara", 31), but it can't be changed after it's made. Use one for a small fixed group of values that belong together: a name and a score, a date, a pair from enumerate. Read items with an index (pair[0]) or unpack them: name, score = pair. You've already met them: d.items() gives tuples.

Why not range(len(items))?

for i in range(len(items)): x = items[i] works, but it has two extra chances for bugs (the wrong length, the wrong index) and it's harder to read. enumerate says exactly what you mean. Use range(len(...)) only when you need to look at other positions too, like items[i + 1].

Real-work scenarios

Scenario 1: A numbered menu

options = ["View balance", "Transfer", "Log out"]
for n, option in enumerate(options, 1):
    print(f"{n}. {option}")
choice = int(input("Choose: "))
print("You chose", options[choice - 1])     # convert human number back to index

Humans count from 1, lists from 0. enumerate(…, 1) for display, then - 1 to get back to the index. That one-line conversion appears in every menu-driven program.

Scenario 2: Error reports with line numbers

lines = ["Sara,42", "Omar,abc", "Lina,35"]
for line_no, line in enumerate(lines, 1):
    name, age = line.split(",")
    if not age.isdigit():
        print(f"Line {line_no}: bad age {age!r}")    # Line 2: bad age 'abc'

When you validate a file, telling the user which line is wrong is the difference between a useful tool and a frustrating one. Notice repr from the last deep dive, used in the message.

Scenario 3: Finding positions

temps = [12, 25, 18, 25, 9]
hot_days = [i for i, t in enumerate(temps) if t == max(temps)]
print(hot_days)      # [1, 3]   both positions of the maximum

Scenario 4: Do something different for the first item

for i, word in enumerate(["hello", "world"]):
    if i == 0:
        word = word.capitalize()
    print(word, end=" ")      # Hello world

Use it well

  • Default to for item in items. Reach for enumerate only when you actually need the number.
  • Use enumerate(x, 1) for anything humans read; keep 0-based for indexing.
  • It works on any iterable: strings (character positions), files (line numbers), dict items.
