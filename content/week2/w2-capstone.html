Capstone: the word counter, explained with loop eyes

40 minEvery token explained · 4 extensions

The program you asked about at the start uses almost everything from this week: a function, a list, a list comprehension, a for loop, a dict tally, sorting, and writing a CSV file. Tap through every piece of it.

Which patterns are in it?

  • Transform: [word.lower() for word in words] turns every word lowercase (a comprehension is the transform pattern in one line).
  • Tally: the for loop with if word in counts counts each kind of word.
  • Sort + loop: sorted(counts.items(), key=..., reverse=True) then a loop writes each row.

File handling with open and with is covered fully in Week 6. The anatomy explorer above explains it now so nothing stays mysterious. One more file tool you'll use in the projects: f.read().splitlines() gives a list with one string per line, without the line breaks.
