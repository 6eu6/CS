while: repeat as long as something is true

40 minAnatomy · trace · 8 predictions · 5 exercises

while is the simplest loop in Python: it's an if that keeps coming back. Understand it completely and every other loop will be easy.

The idea in plain English

"While the kettle isn't boiling, wait one more second." You check a condition; if it's true you do the body; then you go back and check again. You stop the first time the check is false.

Why the condition is checked at the top

Python checks the condition before each pass, including the first. So if n starts at 0, the body runs zero times. A while loop can run 0, 1, or a thousand times; the condition alone decides.

Counting up and the "off-by-one" bug

i = 1
while i <= 5:     # <= includes 5
    print(i)
    i += 1         # shorthand for i = i + 1

Change <= to < and you get 1 to 4. Start at 0 and you get 0 to 5. Being one too many or one too few is so common it has a name: the off-by-one error. The cure is to trace the first and last iterations by hand: "what is i the first time? the last time?"

Infinite loops, and how to escape one

i = 1
while i <= 5:
    print(i)       # forgot i += 1  →  prints 1 forever

In your Codespace terminal, press Ctrl+C to stop a running program. In the runners on this site, programs are stopped automatically after 5 seconds.

Sometimes an infinite loop is exactly what you want: while True: runs forever until something inside it stops it with break or return. Lesson 3 is all about that.

while loops that aren't about counting

while shines when you don't know in advance how many iterations you'll need:

balance = 100
years = 0
while balance < 200:          # how many years until the money doubles?
    balance = balance * 1.05
    years += 1
print(years)                  # 15
n = 4096
digits = 0
while n > 0:                  # how many digits does a number have?
    n = n // 10               # drop the last digit
    digits += 1
print(digits)                 # 4
Where while appears in real software

Game loops (keep drawing frames while the game isn't over), servers (keep handling requests while running), retrying a download while it keeps failing, reading a file while there are lines left, and every "ask again until the answer is valid" form.
