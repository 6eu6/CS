f-string formatting: output that looks professional

40 minFormat lab · 5 exercises
The question it answers

"How do I line up columns, show money, percentages, signs and padded numbers, so the output looks like a real report?"

The format spec, every character

After the colon inside { } comes a mini-language. Its parts always come in this order (all optional):

PartExampleMeaning
fill + align{x:<10} {x:>10} {x:^10} {x:*^10}Left / right / centre in 10 characters; optional fill character before the arrow
sign{x:+}Always show + or −
zero pad{n:03}Width 3, padded with zeros: 007
width{x:8}At least 8 characters wide
grouping{x:,}Thousands separators
precision{x:.2f}2 decimals
typef % d efixed decimals, percentage (×100), integer, scientific

Try:

  

  
Building a table


rows = [("Tea", 2, 1.8), ("Chocolate cake", 1, 3.1)]
print(f"{'Item':<16}{'Qty':>4}{'Price':>9}")
print("-" * 29)
for name, qty, price in rows:
    print(f"{name:<16}{qty:>4}{price:>9.2f}")


Item             Qty    Price
-----------------------------
Tea                2     1.80
Chocolate cake     1     3.10

  
Text is usually left-aligned and numbers right-aligned, so decimal points line up. That's the convention in every spreadsheet and receipt.

  
Dynamic widths


width = max(len(name) for name, _, _ in rows) + 2
print(f"{'Item':<{width}}Qty")        # a { } inside the spec uses a variable

  
Real-work scenarios

  
    
    
  • Invoices and receipts: £{total:,.2f}, aligned columns.
    • 
    
  • Reports: {growth:+.1%} shows +12.5% or -3.0%.
    • 
    
  • IDs and file names: f"INV-{n:05}" → INV-00042; f"photo_{i:03}.jpg" sorts correctly as text.
    • 
    
  • Times: f"{h}:{m:02}:{s:02}".
