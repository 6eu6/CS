A variable holds one value. A list holds as many as you like, in order. Loops and lists belong together: the list stores the data, the loop processes it.

The classic trap: items = items.sort()
.sort() changes the list and returns None. So items = items.sort() throws your list away and stores None. Use items.sort() alone, or new = sorted(items).


  
Three ways to loop over a list


students = ["Sara", "Omar", "Lina"]

for s in students:                  # 1. just the items (use this by default)
    print(s)

for i in range(len(students)):      # 2. the positions; you need students[i]
    print(i + 1, students[i])

for i, s in enumerate(students, 1): # 3. both at once, counting from 1
    print(i, s)

Building a list with a loop

  


temps = [14, 22, 19, 25, 17]
warm = []
for t in temps:
    if t > 18:
        warm.append(t)
print(warm)        # [22, 19, 25]



  
List comprehensions: the same thing in one line

  
"Make a new list from an old one" is so common that Python has a short form for it, the list comprehension:


warm = [t for t in temps if t > 18]              # keep some (filter)
doubled = [t * 2 for t in temps]                   # change each (transform)
clean = [w.strip().lower() for w in words if w.strip()]   # both

  

    
[ ]
The result is a new list.

    
t * 2
The expression: what goes into the new list for each item. Written first, run per item.

    
for t in temps
The loop part: same as a for loop header, without the colon.

    
if t > 18
Optional filter: only items where this is True are kept.

  

  
Read it out loud: "a list of t * 2, for each t in temps". Use a comprehension for "transform and/or filter a list"; use a normal for loop when you need several steps per item. CS50P covers these again in Week 9.


  
Two names, one list


a = [1, 2]
b = a           # b is the SAME list, not a copy
b.append(3)
print(a)        # [1, 2, 3]  ← a changed too!
c = a.copy()    # a real, separate copy

  
Assignment never copies a list; it adds another name to the same list. This surprises everyone once. Strings and numbers don't have this issue because they can't be changed in place.
