zip(): walking several lists in step

30 min4 scenarios · 6 predictions · 4 exercises
The question it answers

"I have related data in separate lists. How do I go through them together, item by item?"

The name

Like a zip on a jacket: two separate sides joined tooth by tooth.

Anatomy

names = ["Sara", "Omar", "Lina"]
scores = [88, 72, 95]
list(zip(names, scores))       # [('Sara', 88), ('Omar', 72), ('Lina', 95)]
dict(zip(names, scores))       # {'Sara': 88, 'Omar': 72, 'Lina': 95}
zip stops at the shortest list

zip([1, 2, 3], ["a", "b"]) gives only 2 pairs. The 3 is silently dropped. When lists should be the same length, check len(a) == len(b) first, or you can lose data without any error.

Real-work scenarios

Scenario 1: Columns from a spreadsheet

header = "name,dept,salary".split(",")
row = "Sara,IT,42000".split(",")
record = dict(zip(header, row))
print(record["dept"])      # IT

Turning a header row and a data row into a dict is exactly what csv.DictReader does inside (Week 6). Now you know how it works.

Scenario 2: Before vs after

last_week = [120, 98, 143]
this_week = [135, 90, 143]
for old, new in zip(last_week, this_week):
    change = new - old
    print(f"{old} → {new}  ({change:+})")     # :+ shows the sign: +15, -8, +0

Scenario 3: Neighbours in one list

readings = [10, 14, 13, 20]
for a, b in zip(readings, readings[1:]):
    print(b - a)            # 4, -1, 7   change between consecutive readings

Zipping a list with itself shifted by one gives every pair of neighbours. It's a classic trick for "change since last time", spotting jumps in sensor data or prices.

Scenario 4: Combine with enumerate

for rank, (name, score) in enumerate(zip(names, scores), 1):
    print(rank, name, score)

Note the brackets (name, score): enumerate gives (rank, pair), and the inner brackets unpack the pair.
