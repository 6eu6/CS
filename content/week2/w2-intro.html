A loop lets a few lines of code run hundreds or millions of times. Combined with lists and dictionaries, which hold many values at once, loops are what make programs actually useful.

Why loops exist

Imagine printing the numbers 1 to 1,000. Without a loop you'd write 1,000 print lines. With a loop:

for i in range(1, 1001):
    print(i)

Two lines. And if tomorrow you need 1 to 1,000,000, you change one number. That's the whole idea: describe the repeated work once, let the computer repeat it.

What you'll be able to do

  • Write while loops that run until a condition changes, and for loops that walk through a sequence.
  • Control loops precisely with range, break, continue and return.
  • Keep asking a user until their input is valid (the most common real-world loop).
  • Store many values in lists and look things up by name in dictionaries.
  • Use loops inside loops for grids and patterns.
  • Recognise the seven classic loop patterns (sum, count, max, filter, search, build, tally) so that new problems look familiar.
