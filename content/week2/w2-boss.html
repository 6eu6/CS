Boss level: hard problems

4–6 hours14 hard exercisesArrange, fill, bug-hunt

These are deliberately harder than CS50P's problem sets. Each one combines several patterns and makes you design the solution before typing. If you can solve most of them on your own, you've truly mastered loops.

How to attack a hard problem
  1. Solve one example by hand on paper. Write down every intermediate value. That's your algorithm.
  2. Name the patterns: "this is a tally, then a max".
  3. Write the plan as comments, one per step.
  4. Code one comment at a time and print intermediate values with repr.
  5. Test the edge cases: empty input, one item, all equal, negatives.
